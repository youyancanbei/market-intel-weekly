# 参考 · 市场情报周报流水线

## 1. 信息源库 Excel 字段与规则

台账建议列：`来源ID, 来源名称, 官网/栏目链接, 链接核验状态, 核验说明, 链接来源, 渠道类型, 来源类别, 产业环节, 信息类型, 国家/地区, 来源性质, 优先级, 关注重点/跟踪内容, 对报告的价值/注意事项, 引用热度, 免费/付费, 采集方式, 监控频率, 最近核验日期, 负责人, 来源文档, 备注`。

- 优先级：`★核心`（首版周报必接）/ `常规` / `补充`。
- 来源性质：监管原文 / 企业披露 / 独立研究 / 媒体 / 社区。
- 产业环节（交叉维度）：政策 · 芯片·半导体 · AI基础设施 · 模型 · Agent · 能源 · 舆情 · 投融资/财务。

**去重**：key = (归一化名称, 渠道)。归一化：去空白、全角括号转半角、小写。跨文档同名同渠道合并（来源文档标双方、关注点拼接、优先级取最高）；官网 vs 公众号分列两行。

**链接核验**（并发 python，无 soffice 也可跑）：`urllib` GET，UA 伪装，超时 10–12s，先 `quote()` 中文 query（否则搜狗微信等中文 URL 会误报）。分类：✅可访问 / 🔒受限·链接有效(403·412·429·TLS握手) / ⏳超时(可能需代理) / ❌域名无法解析(疑似失效/写错) / —无链接。境外站 403/超时 ≠ 失效，别当坏链删。
**补缺链接**：只填**有把握的官方域名**，标"整理补充(推断)"；小众 A 股/初创宁缺毋滥留空。常见坑：缺 `www.`（cninfo/ggzy/gsxt/hkexnews/ccgp 等）、`.com` 误写 `.cn`、中微=`amec-inc.com`、浪潮=`inspur.com`、ASE=`ase-global.com`。

## 2. 采集 agent 提示模板（按主题派发）

```
你是一名{领域}情报分析师。今天是 {今天}。请联网检索 {起} 至 {止} 内、与"{主题}"直接相关的高信号事件，供{本公司}市场情报周报使用。
严格规则：
- 只收录能通过 WebSearch/WebFetch 找到真实来源、发布时间落在区间内的事件；禁止编造标题/日期/链接；日期不明确则丢弃。
- 每条输出：- **YYYY-MM-DD** 标题 —— 来源：名称（URL）。要点：…。→ 对本领域意味着：…。
- 优先这些核心信源：{该主题核心源清单}；厂商公告/官方数据/交易所披露优先；"据知情人士/外媒曝"须标注未经官方证实；SEO 博客/股吧/百科的型号·参数·跑分默认不采信。
- 关注方向：{3-6 个信号问题}。
检索建议：对每个方向 2–3 次中英 WebSearch，必要时 WebFetch 核对日期与数据。
输出 ≤10 条、去重、按重要性；末尾附"未覆盖说明"（搜过但区间内无可靠结果的方向）。全程中文、简洁。
```

主题簇建议：政策与出口管制 / 芯片供需·价格·供应链 / AI基础设施·数据中心·云 / 能源电力 / 模型·Agent·开源 / 厂商动态 / 资本市场·投融资·采购 / 海外媒体。

## 4. 事实核查报告模板 + agent 提示

报告结构：概述（范围/方法/判定档位）→ 逐项（原表述→判定→依据(来源+URL+日期，优先一手)→处理建议）→ 汇总表（#|待核项|判定|处理）→ 总体结论。判定档位：✅属实 / 🟡部分属实(修正或剥离未经证实数字) / ⚫无法证实·疑似不实(降级或删除)。

核查 agent 提示：
```
你是一名事实核查员。今天是 {今天}。用 WebSearch/WebFetch 逐条核查以下"存疑"条目，优先厂商官方/交易所/政府官网/权威媒体一手；宁可"无法证实"也不臆断为真。对仅见于 CSDN/SEO 镜像/股吧/百科/搜狐号的型号名·参数·跑分高度警惕。
待核项：{列表，含原表述}
每条输出：判定(属实/部分属实需修正/无法证实/疑似不实) + 依据(2–4 来源+URL+日期) + 建议(保留/更正为…/降级为传闻/删除)。末尾给整体可信度总结。
```
核查后**回写清单与周报**：删无据断言（如虚构的政策量化口径/未发布的型号）、把媒体转引升为已核实、补数据口径（营收份额 vs 位元份额）、修正日期/价格分档，并在页尾或独立报告中留判定表。

## 5. report.json → 邮件周报 HTML

`python scripts/build_weekly_html.py report.json 周报.html`

顶层键：`title, eyebrow, coverage, overview[{head,body}], sections[]`。每个 section：`num, title, sub, accent(hex), layout, note?` + 对应版式数据。layout 取值：
- `card`：`cards[{date,title,tags[],point,imp,links[[name,url]]}]`（政策/基础设施/厂商卡片）
- `kpi+table`：`kpis[{value,label,source,color}]` + `headers[],colw[],rows[[...]]`（供需）
- `table`：`headers[],colw[],rows[]`（模型可信度表 / 资本表；单元格可放 `tag('属实')` 之类 HTML，或纯文本）
- `timeline`：`cards[]`（厂商时间线，**不渲染 tags**，页面无多余 span）
- `callout+card`：`callout{label,big,body}` + `cards[]`（能源）

规则：`imp` 以 `→`/`⚠` 开头原样，否则自动补 `→ `；tags 用已知色键（国内/海外/管制/属实/部分属实/未证实/一手/媒体/待核/中标/政采/融资/研报/行情/并购/设计/存储/整机/资本/财报/政策/规划/绿色/绿电…），未知键给灰。

**品牌抬头**（report.json 顶层可选键）：`logo`（png 路径）或 `logo_b64`（原始 base64）；`brand_en`（英文小字 eyebrow）、`brand_zh`（中文大标题）、`coverage_label`（默认"覆盖区间"）。给了 logo 即切换为"左 logo / 右名称"两栏，覆盖区间移入右栏与文字左对齐；logo 固定 height:58px，正好等于文字块（英文 line-height:20 + 4 + 中文 line-height:34 = 58），两栏 valign:top 实现上/下沿对齐。无 logo 则回退单栏 eyebrow/title。

**logo 白底抠透明**（无透明通道 PNG 预处理）：
```python
from PIL import Image
im=Image.open('logo.png').convert('RGBA'); px=im.load(); w,h=im.size
for y in range(h):
    for x in range(w):
        r,g,b,a=px[x,y]; mn=min(r,g,b)
        if mn>=246: px[x,y]=(r,g,b,0)
        elif mn>=210: px[x,y]=(r,g,b,int(255*(246-mn)/36))
im.save('logo_transparent.png')
```
技能已内置 `assets/logo.png`（曦望透明 logo）作示例。

最小示例见 `scripts/`；把周报里"解说性文字"（采集方法、核查方法、可信度长说明、页脚等）从 `sections/note` 里剔除即可生成"对外纯净版"，仅保留正文事件。

发布：静态站点 = 目录根放 `index.html` → `qwenwork_pages_publish(file_path=<目录>, category="static", name="...")`（仅在用户明确要求发布时）。
